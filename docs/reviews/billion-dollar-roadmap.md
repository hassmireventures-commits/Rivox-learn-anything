# Billion-Dollar Roadmap

## Strategic thesis

Defend **verified learning outcomes** and a **portable learner model**, not prompt wrappers. Local-first privacy is a premium mode; mass market needs instant value without API keys.

## Opportunity map

| Opportunity | Fit to codebase | Horizon |
|-------------|-----------------|---------|
| Personal learning agent | `goal_agent`, orchestrator, recommendations | 6–12 mo |
| Exam/cert packs marketplace | exam module + syllabus models | 12 mo |
| Creator / grounded content market | PKB after real retrieval | 12–18 mo |
| Enterprise L&D / campus | audit + policy + identity needed | 12–24 mo |
| Learning intelligence API | after BFF + evals | 18 mo |
| Privacy-first on-device SKU | MLC path | Now as Pro |
| Network effects (cohorts, shared paths) | rebuild social carefully | 12 mo |

## Growth / retention loops (target)

1. **Activation:** demo lesson → aha → optional account  
2. **Habit:** reminders + daily adaptive quiz  
3. **Investment:** personal library + mastery graph  
4. **Social:** shared packs (moderated)  
5. **Monetization:** free quota → Pro (unlimited, RAG, offline) → Enterprise  

## Moat sequence

1. Trust & quality (evals, citations that work)  
2. Switching costs (library + history sync)  
3. Educator supply side  
4. Outcome network effects (privacy-preserving)

## What not to do early

- Marketplace before moderation + accounts  
- Enterprise SSO before local reliability  
- More incomplete modes before one wedge wins  
- Paid acquisition before freemium unit economics
