**Archive created:** 2026-07-29

## Prerequisites on the new PC

1. **Flutter SDK** matching `pubspec.yaml` constraint **`sdk: ^3.11.5`** (install a stable Flutter that satisfies this; confirm with `flutter --version`).
2. **Android Studio** (or cmdline tools) with Android SDK, platform tools, and a recent build-tools / compile SDK as expected by the project.
3. **JDK** (17 recommended for modern Android Gradle Plugin).
4. **Git** (optional but useful if `.git` was in the zip, or to re-init and connect a private remote).
5. **Firebase CLI** (optional) for Hosting / FlutterFire: `npm i -g firebase-tools` then `firebase login`.

On Windows, add Flutter and Android SDK paths to `PATH`, then run:

```powershell
flutter doctor -v
```

Fix any blockers for Android toolchain before building release APKs.

## Unzip steps

1. Copy `learn-anything-backup-2026-07-29.zip` to the new machine via a **private** channel.
2. Extract to a working parent, e.g. `C:\dev\`:

```powershell
Expand-Archive -Path "C:\path\to\learn-anything-backup-2026-07-29.zip" -DestinationPath "C:\dev\" -Force
```

You should get `C:\dev\learn-anything\` (or rename the extracted folder to that).

3. Open that folder in Cursor / Android Studio / your editor.

## Play signing (critical)

Release / Play uploads need the upload keystore and properties file.

1. Confirm these exist after unzip:
   - `android/key.properties`
   - `android/app/upload-keystore.jks` (and any other `*.jks` / `*.keystore` under `android/`)
   - `android/keystore.local.md` (human notes, if present)

2. Open `android/key.properties` and ensure paths point at the keystore on the **new** machine (relative paths under `android/` usually still work if you keep the same layout).

3. Do **not** commit these files to a public repo. They are typically gitignored.

4. More Play / store context: see [PLAY_LAUNCH_GUIDE.md](PLAY_LAUNCH_GUIDE.md).

## Checklist before wiping the old PC

- [ ] Zip exists and size looks reasonable (not tiny — secrets + full source).
- [ ] Verified inside zip (or staging): `android/key.properties`, at least one `*.jks`, `tool/.local_dart_defines.json`.
- [ ] Zip copied to new PC **and** a second private backup (external drive / encrypted cloud).
- [ ] New PC: unzip → `flutter pub get` → `flutter doctor` clean enough to build.
- [ ] New PC: signed release build succeeds with restored keystore.
- [ ] New PC: Built-in AI path works with restored dart defines.
- [ ] Firebase login works; hosting deploy optional smoke test.
- [ ] Play Console access from new machine (browser / account).
- [ ] Only then wipe or reimage the old PC.
